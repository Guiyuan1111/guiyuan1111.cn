# v1.0.8（2026-09-27）

基于 v1.0.7：**评论系统永久停用**，组件整套移出构建并归档。

## 变更

- **文件归档**（`git mv` 保留历史）：新建 [comment-backup/](../../comment-backup/)，装入 7 个文件
  —— `src/components/Comment/` 4 个组件（Index/Giscus/Twikoo/Waline，412 行）、
  `src/styles/comment.css`（208 行）、`public/giscus/` 2 个主题样式（约 14KB）。
- **接入点全部注释**：
  - `src/config.ts` 的 `comment` 整块（`enabled` + giscus/twikoo/waline 三配置）
  - `src/types/index.d.ts` 的 `comment` 类型字段
  - `src/layouts/Layout.astro` 的 `MarginBottom` 三元表达式 → 恒定 `mb-12`
  - `src/pages/posts/[slug].astro` 的 `import Comment`、`comment.css`、`<Comment />`
  - `src/i18n/config.ts` 的 `giscusLocaleMap` / `twikooLocaleMap` / `walineLocaleMap` 三套语言映射
- **依赖移除**：`@waline/client`（^3.13.0）与 `twikoo`（^1.7.7），`pnpm-lock.yaml` 已同步。
- **归档目录排除检查**：`tsconfig.json` 的 `exclude` 增加 `comment-backup`、`i18n-backup`；
  `eslint.config.mjs` 的 `ignores` 增加 `comment-backup/**`。
- **文档**：新增 [comment-backup/README.md](../../comment-backup/README.md)（清单 + 6 步恢复法）；
  `note/disabled-features.md` 新增第 3 节；README 功能裁剪章节更新，并修正站点身份描述
  （评论地址已随评论系统移除，不再是待站点化项）。

## 为什么 locale map 也要注释

三套评论语言映射原本只被 `Comment/{Giscus,Twikoo,Waline}.astro` 引用，评论组件移出后即成死代码。
注释后 `src/i18n/` 的值引用从 16 处降至 13 处，i18n 面进一步缩小。

## 验证

- `pnpm check` 0 errors / 0 warnings / 0 hints（覆盖文件 59 → 55，4 个评论组件移出检查范围）
- `pnpm lint` 通过；`pnpm install` 成功移除两棵依赖子树
