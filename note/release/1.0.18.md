# v1.0.18（2026-09-30）

剩余固定串字集收窄（R7）：把 R5 的「渲染角色决定字集」逻辑应用到 Snell-Bold 与
STIX-Italic，完成字体侧收尾。完整数据与三轮累计见
[report/perf/2026-09-30-webfont-charset-r7.md](../report/perf/2026-09-30-webfont-charset-r7.md)。

## 变更

- **Snell-Bold**（日期，`dateFormat` 为 config 固定格式）：字集从
  「∪ A-Za-z0-9」收窄为「∪ 数字 ∪ 日期标点」，12.6 → 2.2KB；
- **STIX-Italic**（导航/页脚/404，固定串）：从「∪ 全 ASCII」收窄为
  「∪ 数字 ∪ 标题标点」，18.8 → 5.0KB；
- 不动：STIX（serif 正文全 ASCII 红线）、Snell-Black 与 EarlySummer-Subset（R5 已收）；
- dateFormat 切换为含英文月份的变体时需重跑 `gen:uifonts`（已写入 font-subset.md 与脚本注释）。

## 验证

- 每页引用资产中位数 52.5 → **42.1KB（-19.8%）**；真实浏览器每页 webfont 46.1 →
  **21.8KB（-52.7%）**；
- 门禁：sans **45/45**、serif **45/45**（median 109.6KB）；
- `pnpm lint` 0 问题、`pnpm check` 0 错误、`pnpm build` 45 页正常。

## 三轮累计（v1.0.15 → v1.0.18）

每页引用资产中位数 -49.7%、webfont -72.4%、预载合计 -72.1%、部署产物 -47.6%（R6）。
