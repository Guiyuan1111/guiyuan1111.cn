# v1.0.7（2026-09-27）

基于 v1.0.6：**路由彻底去 i18n** —— `src/pages/[...lang]/` 改名为普通路径，`src/pages/` 下不再有任何 i18n 引用。

## 变更

- **路由改名**（`git mv` 保留历史）：

  | 原路径 | 新路径 |
  | --- | --- |
  | `src/pages/[...lang]/index.astro` | `src/pages/index.astro` |
  | `src/pages/[...lang]/about.astro` | `src/pages/about.astro` |
  | `src/pages/[...lang]/posts/[slug].astro` | `src/pages/posts/[slug].astro` |
  | `src/pages/[...lang]/tags/index.astro` | `src/pages/tags/index.astro` |
  | `src/pages/[...lang]/tags/[tag].astro` | `src/pages/tags/[tag].astro` |
  | `src/pages/[...lang]/rss.xml.ts` | `src/pages/rss.xml.ts` |
  | `src/pages/[...lang]/atom.xml.ts` | `src/pages/atom.xml.ts` |

- **移除 lang 参数与语言版 `getStaticPaths`**：`index`/`about`/`tags/index`/`rss.xml`/`atom.xml`
  五个非动态路由的 `getStaticPaths` 直接删除（改名后本就不会被调用，留着是死代码）；
  `posts/[slug]` 与 `tags/[tag]` 保留 `getStaticPaths` 但去掉 `lang` 参数，
  内容筛选改为 `post.data.lang === defaultLocale || post.data.lang === ''`。
- **`currentLang` 改取 `defaultLocale`**：各路由不再经 `getLangFromLocale(Astro.currentLocale)`，
  消除对 `Astro.currentLocale` 的依赖（类型为 `Language`，与原返回值一致）。
- **`src/i18n/lang.ts` 清理**：`getLangRouteParam`、`getLangFromLocale` 在路由去 i18n 后零调用方，
  连同 `langMap` 导入一起注释；文件内标注唯一仍被调用的 `getLangFromPath`（Footer、utils/page、i18n/path）。
- **文档同步**：`note/disabled-features.md` 增加第 ④ 阶段与路由恢复步骤、重算 i18n 引用数（21 → 16）；
  README 自定义章节更新。

## 保留未动

| 保留项 | 原因 |
| --- | --- |
| `astro.config.ts` 的 `i18n` 块 | `Layout.astro` 的 `<html lang>` 依赖它；注释会丢 lang 属性，使 `uno.config.ts` 的 `cjk:` 变体失效 |
| `src/i18n/` 四个文件 | 仍有 16 处静态值引用（astro.config、content.config、Footer、utils/*、PostList/TagList、3 个评论组件、Navbar/Header/TOC/Head、feed、types） |
| `src/pages/` 的 `currentLang` | 是正文筛选条件与组件 `lang` prop 的来源，与 i18n 机制无关 |
| `rss.xml.ts`/`atom.xml.ts` 的 `params?.lang` | `feed.ts:143-145` 读不到该值时回退 `defaultLocale`，无需改动 feed 层 |
