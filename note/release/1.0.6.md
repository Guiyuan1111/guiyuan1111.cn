# v1.0.6（2026-09-27）

基于 v1.0.5：多语言由「暂时禁用」升级为**永久停用**，文件集中备份，并清理页面中的语言概念。

## 变更

- **多语言文件集中备份**（`git mv` 保留历史）：新建 [i18n-backup/](../../i18n-backup/)，装入
  45 篇外语文章与关于页（原 `src/content/_archive/`）+ 6 份主题 README 翻译（原 `assets/docs/`）+
  语言切换按钮图标，共 **52 个文件**，全部脱离构建管线。
- **清理页面里的语言概念**：
  - `posts/[slug].astro` 的 `slugToLangsMap` 同 slug 多语言聚合整块注释（约 27 行）、`supportedLangs` 传递链注释
  - `tags/[tag].astro` 的 `getTagSupportedLangs` 调用与导入注释
  - `Layout.astro` 的 `supportedLangs` 声明、解构与向 `<Button>` 的传参注释
  - `Button.astro` 的 `Props.supportedLangs` 与 `Language` 类型导入注释
- **注释 hreflang 备选链接块**（`Head.astro`）：单语言下只输出一条指向首页的 `hreflang="zh"`，无 SEO 价值；同时移除随之失效的 `allLocales`/`defaultLocale` 导入。
- **各处加「多语言已永久停用」横幅**：`src/i18n/` 4 个文件顶部说明为何不能删除（21 处静态引用）；`astro.config.ts` 的 i18n 块说明为何不能注释（`<html lang>` 与 `uno.config` 的 `cjk:` 变体依赖）。
- **eslint 忽略 `i18n-backup/**`**：归档的 markdown 不参与代码检查（原先靠 `src/content/**` 忽略规则覆盖）。
- **文档同步**：`note/disabled-features.md` 重写为三阶段时间线 + 保留项原因 + 恢复方法；`i18n-backup/README.md` 新增归档清单与恢复步骤；README 自定义章节更新（并修正站点身份描述：`site.url` 与 `author` 已站点化）。

## 明确保留、未动的部分

| 保留项 | 原因 |
| --- | --- |
| `astro.config.ts` 的 `i18n` 块 | `Layout.astro` 的 `<html lang>` 依赖它；注释会丢 lang 属性，使 `uno.config.ts` 的 `cjk:` 变体失效 |
| `src/i18n/` 四个文件 | 21 处静态值引用（astro.config、content.config、7 个路由、Footer、PostList/TagList、utils/page、3 个评论组件、Navbar/Header/TOC/Head/feed），删除即构建失败 |
| `[...lang]` 路由目录 | 只生成根路径页面，改名收益极小却要动 7 个路由并连带 `feed.ts` 的 `params.lang` |
| 9 篇 `*-zh.md` 与 `about-zh.md` | 是站点唯一正文，移动会导致站点空白 |
