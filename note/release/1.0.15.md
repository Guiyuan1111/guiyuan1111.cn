# v1.0.15（2026-09-29）

字体加载性能专项：四轮优化（R1–R4），每轮以真实浏览器门禁（42/42 页双模式）验证后提交。
完整数据与口径说明见 [report/perf/2026-09-29-font-performance-r1-r4.md](../report/perf/2026-09-29-font-performance-r1-r4.md)。

## 变更

- **R1 分片重切分**：EarlySummer 47 个分片按页面共现频率聚类重切（同源校验 + 脚本入库
  `scripts/split-earlysummer.py`，移除 cn-font-split 运行时依赖）。serif 假设口径最重页
  分片流量 2 256 KB → 1 217 KB。
- **R2 页面级精确子集**：`scripts/gen-page-fonts.py` 按页生成仅含该页字符的 woff2，
  `scripts/apply-page-fonts.mjs` 构建后注入页面级 `@font-face`（后声明赢层叠，缺字回退分片
  自愈）；仅 serif 模式注入，默认 sans 模式零成本。serif 模式每页只拉 1 个字体
  （门禁中位数 ≈169 KB）。
- **R3 UI 字体子集**：`scripts/subset-ui-fonts.py` 将 Snell-Black / Snell-Bold / STIX-Italic /
  STIX 按站点实际用字子集（68/40/52/46 KB → 18.1/16.6/19.5/17.7 KB）。真实浏览器每页
  webfont 传输 191.1 KB → 79.1 KB。
- **R4 分片 CSS 条件加载**：47 个分片 `@font-face` 拆出 `src/styles/earlysummer-shards.css`，
  仅 serif 构建产出并引用（sans 构建连文件都不生成）。每页引用资产 gzip
  中位数 179.6 KB → 85.7 KB（四轮累计 -52.2%）。
- **基准与门禁套件**（`benchmark/`）：page-weight / font-traffic 基准 + CDP 真浏览器
  `font-cascade-check.mjs`（零依赖，内置静态服务器与桌面视口，宽度探针防假通过），
  历次快照 JSON 入库 `benchmark/results/` 作为证据。
- 修复：`apply-page-fonts.mjs` 注入锚点由首个改为最后一个 head 闭合标签（HTML 注释中
  出现该字面量时原实现会把样式注入注释内部导致层叠失效）。
- 文档：[font-subset.md](../font-subset.md) 更新（47 分片、config.ts 文案来源、UI 字体
  子集步骤、双脚本分工），新增 R1–R4 对比报告，benchmark/README 口径说明。

## 验证

- `font-cascade-check.mjs` 双模式 42/42 页 PASS（R2/R3/R4 每轮后各跑一次）：
  sans 模式 EarlySummer 家族零请求、渲染探针通过；serif 模式每页恰好 1 个页面字体、
  0 分片泄漏；两模式均无 console 错误与 JS 异常。
