# v1.0.13（2026-09-29）

诗歌顶格：含硬换行的段落不再首行缩进。

## 变更

- `src/styles/markdown.css` 缩进规则追加 `:not(:has(br))`：段落内含 `<br>`（即 markdown 硬换行 `\`）时保持顶格。散文段落无 `<br>`，照常缩进 2em。
- 《致恰达耶夫》由 21 个逐行独立段落改写为单个带硬换行（`\`）的段落，全诗顶格显示；行序与文字未做任何改动。

## 诗歌书写约定（后续发文适用）

- 诗歌写成**一个段落 + 行尾 `\` 硬换行**（诗节之间空一行分段），即可顶格；普通散文段落照常首行缩进。
- 判定纯靠 CSS `:has(br)`，无需在文章里打任何标记类。

## 说明

- `:has()` 为现代浏览器标准特性（2023 起全面支持）；不支持的旧浏览器退化为全段落缩进。
- 原始 docx 中诗节间无空行，未凭记忆补诗节划分，保持原文行序。

## 验证

- `pnpm build` 42 页正常；`dist/posts/致恰达耶夫/index.html` 中全诗为单段落、含 20 个 `<br>`；构建 CSS 规则输出为 `...:not(:has(br)){text-indent:2em}`。
