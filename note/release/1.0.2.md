# v1.0.2（2026-09-27）

基于 v1.0.1 的构建与部署性能优化（性能分析报告三项 P0 落地）。

## 变更

- 构建期专用字体移出 `public/`：NotoSansSC Bold/Regular（共 16MB，仅 OG 图构建期渲染使用）迁至 `src/assets/fonts/`，不再随部署产物发布
- `dev`/`build` 脚本移除 `astro check`：类型检查改为独立步骤（CI/lint 阶段执行），不再阻塞每次启动与构建
- 移除 `astro-compress` 集成：HTML/JS/CSS 压缩由 Astro（compressHTML 默认开启）与 Vite（esbuild minify）默认覆盖，构建期少一遍全量 dist 后处理

## 性能（实测）

- 部署产物字体部分 21MB → 4.0MB（dist 中 OTF 文件数 2 → 0），部署总体积 -16MB
- 每次构建与 dev 启动省去一次全量类型检查（`astro check` 实测单次 18.6s / 59 文件）
- 构建回归验证：18 页 / astro build 42.98s；OG 图 49 张全部生成；LQIP 16/16 缓存命中、18 张应用
- `astro check` 独立复检：0 errors / 0 warnings / 0 hints
