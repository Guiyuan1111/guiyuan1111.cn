# v1.0.16（2026-09-30）

字体预载收窄专项（R5）：UI 显示字体子集按渲染角色语义化收窄 + EarlySummer-Subset
数据驱动重建 + serif 页面字体回归修复。完整数据见
[report/perf/2026-09-30-font-preload-slimming-r5.md](../report/perf/2026-09-30-font-preload-slimming-r5.md)。

## 变更

- **UI 子集字集策略化**（`scripts/subset-ui-fonts.py`）：Snell-Black（仅站点标题）收窄为
  「用字 ∪ 数字 ∪ 标题标点」17.9→3.1KB；Snell-Bold（日期）保留 A-Za-z0-9 ∪ 日期标点
  16.5→12.6KB；STIX / STIX-Italic 维持全 ASCII 口径不动（serif 正文安全）。首屏预载合计
  **59.2 → 27.2KB（-54%）**。
- **EarlySummer-Subset 重建**：剔除上游多语言遗留字符（约 20 个日文/繁体字），改为从
  dist 实测 `font-title`/`font-navbar` 文本收集 CJK（18 字）∪ 常用 CJK 标点边距，共 34 码位；
  name 表收敛为仅 UniqueID。24.8 → **11.2KB**，fvar（250–900）与 unicode-range 同步受断言保护。
- **回归修复**（serif）：`gen-page-fonts.py` 自 R4 分片 CSS 拆分后只解析 `font.css`，
  分片流量恒为 0、所有页面 skip，serif 页面字体实际无法再生；修复为解析
  `font.css + earlysummer-shards.css` 双源，并按当前 45 页内容重新生成 manifest（7.19MB）。

## 验证

- page-weight：median **83.7 → 52.5KB（-37.3%）**、max 124.4 → 93.2KB（-25.1%）；
- 真实浏览器门禁：sans **45/45**（webfont 79.1 → 46.1KB/页，-41.7%）、serif **45/45**
  （页面字体中位数 169.0 → 133.8KB）；两模式均无 console 错误与 JS 异常；
- `pnpm check` 0 错误、`pnpm lint` 通过、`pnpm build` 45 页正常。
