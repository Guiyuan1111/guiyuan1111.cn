# v1.0.3（2026-09-27）

基于 v1.0.2 的运行时与流程优化（性能分析报告 P1 三项落地）。

## 变更

- KaTeX 样式按需加载：新增文章 frontmatter 字段 `math: true`（默认 false），仅标记文章注入 KaTeX 样式表；已为 6 个 KaTeX Demo 文章（全语言变体）补上标记
- og:image 去第三方依赖：新增构建期静态首页 OG 图（`/og/home.png`），首页/标签/关于页等非文章页统一回退到该图，彻底移除 apiflash 实时截图回退（含上游作者遗留的硬编码 key）
- 新增 GitHub Actions CI（`.github/workflows/ci.yml`）：lint + typecheck 与 build 两个 job，配合上一版拆出的 `astro check`（新增 `pnpm check` 脚本）
- eslint 忽略 `note/` 文档目录（报告与笔记不参与代码检查）

## 性能（实测）

- KaTeX 样式表（~23KB gzip + 字体探测）从全站 18 页收敛到 1 页（仅数学文章）
- 社交爬虫 og:image 获取从第三方实时截图（秒级、依赖他人配额）变为本地静态图（即时）
- 全量校验：`pnpm lint` 0 问题、`pnpm check` 0 errors / 0 warnings / 0 hints
- 构建回归：18 页 / astro build 28.04s（热缓存）；OG 图 50 张（49 文章 + 1 首页）；LQIP 16/16 缓存命中
