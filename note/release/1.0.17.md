# v1.0.17（2026-09-30）

部署体积清理专项（R6）：与 R5（访客带宽）互补的另一个优化面——每次发布上传 CDN 的
dist 足迹。完整数据与放弃项记录见
[report/perf/2026-09-30-deploy-weight-r6.md](../report/perf/2026-09-30-deploy-weight-r6.md)。

## 变更

- **部署产物 20.31 → 10.64MB（-47.6%）**，访客侧逐字节零回归：
  - `apply-page-fonts.mjs`：sans 构建删除 dist 内未引用的 serif 页面字体（46 个 woff2，-7.2MB）；
  - 新 `scripts/optimize-dist.mjs`（构建链末步）：og PNG 调色板重编码（24 张，-1.38MB，
    仅在更小且尺寸不变时替换）+ KaTeX woff/ttf 遗留裁剪（40 个文件，-0.78MB，woff2 引用数断言不变）；
  - 源字体（Snell/STIX 4 个）与上游分片清单移出 `public/` → `src/assets/fonts/`、
    `scripts/data/font-subset-lists/`（-340KB，再生成素材不随站部署）。
- **基准套件新增 `deploy-weight.mjs`**：dist 总量/分类型/最大文件 + 死重探针
  （earlysummerPages / originalUiFonts / katexLegacyFonts / mermaidChunks / sounds），接入 run-all。
- **门禁健壮性**：`font-cascade-check.mjs` 页面枚举三重回退（dist manifest → public 源
  manifest → 遍历 dist HTML），适配 sans 构建不再携带页面字体的新形态。

## 验证

- page-weight 与基线完全一致（median 52.5KB / max 93.2KB）；sans 门禁 45/45、
  serif 门禁 45/45（median 133.8KB 持平 R5）；
- OG 图抽检：PNG 有效、1200×630、调色板模式；
- `pnpm lint` 0 问题、`pnpm check` 0 错误。
