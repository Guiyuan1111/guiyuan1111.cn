# v1.0.12（2026-09-29）

文章正文段落首行缩进 2 字符（中文书刊排版惯例）。

## 变更

- `src/styles/markdown.css` 新增规则：`#post-content > :where(p:not(.no-heti):not(.no-heti *))` 应用 `text-indent: 2em`。
- 作用域限定：`#post-content` 容器仅存在于 `posts/[slug].astro`，因此只影响文章页正文；关于页、首页不受影响（markdown.css 虽被三处引用，但选择器在其余页面无匹配元素）。
- 仅作用于顶层段落：引用块、列表、figcaption、扩展容器内的段落不缩进。

## 说明

- 用 CSS 而非全角空格实现（v1.0.11 转换时已剥离文档段首全角空格，排版职责归样式层）。
- 《致恰达耶夫》为逐行独立段落，诗行同样缩进 2em；如需诗歌顶格可后续单独处理。
- 纯 CSS 改动，无新增字形，不触及 EarlySummer 字体子集。

## 验证

- `pnpm build` 42 页正常；构建产物 `markdown.*.css` 中规则输出为 `#post-content>:where(p:not(.no-heti):not(.no-heti *)){text-indent:2em}`。
