# v1.0.20（2026-09-30）

基于 v1.0.19 的**不可达资产清扫 R9（部署足迹收尾）**。新增文本级引用闭包分析，构建尾部自动删除任何页面不会请求、任何 chunk 不会加载的产物资产，并固化为 deploy-weight 探针 + CI 红线。

## 变更

- **`benchmark/reachability.mjs`（新）**：零依赖可达性分析——对 `dist/_astro/` 全部 js/css/字体做 basename 全产物文本包含检查（不解析 import 语法，静态/动态导入、css `url()`、preload 一律覆盖），从 HTML 等非候选引用根出发做引用闭包。
- **`scripts/optimize-dist.mjs` 第三步**：删除闭包外不可达资产；页面含 `class="mermaid"`/`class="katex"` 特性标记时整轮跳过（防未知动态加载路径）；自愈——未来数学文章使 KaTeX CSS/字体重新可达后自动保留。本轮实测唯一真孤儿：**KaTeX CSS + 19 字体，20 个文件 276KB**（rehype-katex 构建期渲染，站点无数学内容时只被彼此引用）。
- **回归防线**：deploy-weight 探针 `orphanAstroAssets` + `--assert` 红线（>0 即失败）；负向演练验证植入无引用文件会被 exit 1 拦截。
- 排查结论入库：HTML 块级空白压缩无潜力（compressHTML 后仅剩 1KB/0.1%）；mermaid 客户端图谱经修正后的可达性分析确认为**可达的活特性路径**（`pre-mermaid` 客户端渲染 + MediaEmbed 动态导入字面量），维持 R6 保留决策。

## 验证

- `pnpm build`：`[optimize-dist] sweep: removed 20 unreachable _astro assets (-0.27MB)`。
- 部署足迹 10.62→**10.35MB**（-2.6%），文件 228→208；每页引用资产中位数 43.8KB 逐字节不变；font-traffic 覆盖率 95.8% 不变。
- CDP 真浏览器门禁 sans 45/45 全绿（`r9-gate-sans.json`）；`--assert=final-v1018` 通过；负向演练拦截正常。

## 影响

- 访客侧零变化（被删资产本就无任何页面会请求）；部署上传量再降 0.27MB。
- 对比 v1.0.15 累计：每页资产中位数 -47.7%、webfont -60.4%、部署 -49.1%。
