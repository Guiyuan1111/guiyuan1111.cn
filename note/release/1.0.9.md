# v1.0.9（2026-09-28）

基于 v1.0.8 的**配置唯一化重构 + 站点化收尾 + 性能 P2 清尾**。功能停用从「注释保留」升级为「代码删除」，`src/config.ts` 成为全站唯一配置源。

## 变更

### 配置唯一化（删 i18n 层）

- **删除 `src/i18n/`（4 个文件）**：`ui.ts` 11 语言文案表 → Navbar/TOC 改中文直值、Header/Head/feed 直读 `config.ts`；`path.ts` → 新 `src/utils/path.ts`（无 lang 参数）；`lang.ts`、`config.ts` 无存活职责，随之删除。
- **删除 `astro.config.ts` 的 i18n 块**：`<html lang="zh-CN">` 硬编码进 `Layout.astro`（`uno.config` 的 `cjk:` 变体只依赖 html lang 属性，不受影响）。
- **删除死字段**：`site.i18nTitle`、`global.locale`、`global.moreLocales`、`seo.apiflashKey`（含类型同步）。
- **收链**：content schema 的 `lang` 收紧为 `'' | 'zh'`；`utils/content.ts` 去掉全部 lang 参数与 `getTagSupportedLangs`；`utils/description.ts` 摘要长度固定 CJK；feed 不再接收 lang；组件 `transition:name` 去掉 `-${lang}` 后缀（两端一致，过渡效果不变）。
- 清理 `Button.astro` 中引用已删模块的死注释块。
- 此前「`src/i18n/` 因 13 处静态引用不能删」的结论已被本版推翻：引用可逐处替换，删除后 `src/` 与 `astro.config.ts` 已无任何 i18n 代码引用。

### 站点化收尾

- 清空主题作者遗留：`twitterID`、Google/Bing 验证码、`umamiAnalyticsID` 与自建统计脚本地址（访问数据不再计入作者账号）、`imageHostURL` 图床白名单。
- 页脚 GitHub 链接指向本仓库；移除作者 Email 链接。
- 关于页重写为个人简介（原为主题宣传语），meta description 单源于 `config.ts`（原读 `ui.ts` 的主题宣传语）。
- **删除上游演示内容**：`posts/guides/`（4 篇）、`posts/examples/`（4 篇）、草稿 Universal Post、孤儿图片 `_images/`（15 张）。RSS/Sitemap 不再含上游 URL、图床与已失效的评论配置说明。

### 性能（P2 清尾）

- **wheel 监听条件挂载**（P2-8）：`MediaEmbed` 的 `passive: false` wheel 监听改为仅在页面存在 `.gallery-container` 时挂载（`astro:page-load`/`before-swap` 增减），其余页面保持合成器滚动。
- **移除 partytown 集成**（P2-10）：两个统计 ID 清空后其 Web Worker 运行时成为死重（每页内联 loader + 产物 `~partytown/` 约 108K），集成、依赖 `@astrojs/partytown` 与 `patches/` 补丁一并移除；恢复方法已写入 `astro.config.ts` 注释。
- **字体预载核实**（P2-9）：现存 3 个预载全部服务首屏字体链（标题 Snell-Black、日期 Snell-Bold、CJK UI 子集），v1.0.4 已移除 2 个 STIX 预载，无需再改。

## 验证

- `pnpm lint` 0 问题；`pnpm check` 0 errors / 0 warnings / 0 hints（覆盖 52 文件）。
- `pnpm build` **4 页**（首页/关于/标签/404）+ RSS/Atom/sitemap/robots + OG 首页图。
- `<html lang="zh-CN">`；`<title>` 与 meta description 均来自 `config.ts`；0 hreflang。
- `dist` 体积 41M → **8.6M**（页面/图片减少 + partytown 移除；字体 4.1M 为剩余大头）。
- 产物中无 `~partytown/`、无 partytown loader、无统计请求；页脚无作者 Email。

## 影响

- 配置面大幅缩小：`config.ts` 只剩「改了就生效」的字段，无死开关、无隐藏来源。
- 站点进入空内容状态：写第一篇文章用 `pnpm new-post <标题>`。
- 恢复语义变化：多语言/评论不再可「取消注释即恢复」，需按 [disabled-features.md](../disabled-features.md) 从 git 历史（tag `v1.0.8`）取回。
