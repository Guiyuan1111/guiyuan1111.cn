# v1.0.21（2026-09-30）

基于 v1.0.20 的**加载时序基准 R10（度量维度升级：字节 → 用户感知）**。零站点代码改动，新增两个零依赖基准脚本，并用 git worktree 重建 v1.0.14 起点，完成全战役 R1–R9 的端到端前后时序对比。

## 变更

- **`benchmark/page-timing.mjs`（新）**：CDP 真浏览器逐页计时——缓存禁用、焦点仿真（后台标签不产生 paint 条目的坑已在脚本内处理）、FCP / LCP / DOMContentLoaded / load / wire 传输；wire 双口径区分「本页成本」与含 `prefetchAll` 预取的带宽占用。
- **`benchmark/compare-timing.mjs`（新）**：两份时序快照在共享页面集上的中位数对比 + 按参考带宽（400kbps / Slow 4G / 4G）估算真实网络 FCP。

## 验证（41 页共享页中位数，v1.0.14 → v1.0.20）

- 本页 wire 传输 348→134KB（**-61.5%**）；本地 FCP 44→36ms。
- 预估真实网络 FCP：Slow 4G **1826→722ms（-60.5%）**、普通 4G 400→173ms（-56.8%）、重拥堵 7171→2780ms（-61.2%）。
- 当前最重 LCP（本地）188ms（`posts/加缪的日记/`），均为长文 HTML 解析主导，无传输瓶颈页。
- 站点产物逐字节不变：`--assert` 红线、字节基准与 CDP 字体门禁复核全绿。

## 影响

- 全战役（R1–R9 字节优化）的真实用户感知收益首次量化：Slow 4G 首屏约 1.8s→0.7s。
- 基准套件覆盖「字节（page-weight/font-traffic/deploy-weight）—级联正确性（font-cascade-check）—加载时序（page-timing）」三个维度。
