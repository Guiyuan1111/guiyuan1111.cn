# v1.0.19（2026-09-30）

基于 v1.0.18 的**基准回归门禁 R8 + 字集 used 采集修复**。benchmark 从记录工具升级为可在 CI 长期运行的回归门禁；门禁演练反向揪出并修复 v1.0.16 起潜伏三个版本的字体字集静默丢弃 bug。

## 变更

### 字体字集修复（兼容性回归修复，红线项）

- **修复 `scripts/subset-ui-fonts.py` `class_chars` 返回 str 字符与 int 码点 cmap 求交为空的类型错误**：v1.0.16 起「按 CSS 类名归属的站点实际用字」被静默丢弃，字集只剩数字+标点安全垫。以下文本的字形自 v1.0.16 起一直回退，本版恢复由对应 webfont 渲染：
  - 站点标题 "Guiyuan1111" 拉丁字母（`font-title` / Snell-Black）；
  - 页脚 "RSS / GitHub / Email / Powered by Astro and Retypeset" 整段（`font-navbar` / STIX-Italic）;
  - 列表阅读时长 "min"（`font-time` / Snell-Bold）。
- 重新生成子集：Snell-Black 27→34 cps（3.1→4.3KB）、Snell-Bold 18→21 cps（2.2→2.6KB）、STIX-Italic 27→66 cps（5.0→12.8KB）、STIX 不变；`font.css` unicode-range 由脚本同步修补。

### 基准断言门禁（R8 主体）

- **`benchmark/run-all.mjs` 新增 `--assert` / `--assert=<label>`**：绝对红线（无页面产出 / sans 构建出现页面字体 / 源字体回流 dist / KaTeX woff-ttf 回流 / 字符覆盖率 <95%，全部零容忍、与内容增长无关）+ 可选基线漂移对比（每页中位数 ×1.15、最大值 ×1.25、部署 ×1.5）。
- **CI 接线**：`.github/workflows/ci.yml` build job 末尾新增 `node benchmark/run-all.mjs --assert`（零依赖，无需 Python/浏览器）。
- **负向演练实证**：植入源字体、sans 页面字体目录、KaTeX legacy 字体三类缺陷全部被拦截（exit 1，消息指向根因脚本），清除后恢复 exit 0。

## 验证

- `pnpm lint` 0 问题；`pnpm build` 45 页正常；`node benchmark/run-all.mjs --assert=final-v1018` exit 0（快照 `benchmark/results/r8-final.json`）。
- CDP 真浏览器门禁 sans 模式 45/45 页全绿，每页 webfont 31.3KB（`r8-gate-sans.json`）。
- 端到端字集漂移演练（标题加 JjWw → 回退 → 重新子集 → 覆盖 → 还原）全部按预期，详见 R8 报告第四节。

## 影响

- 每页资产中位数 42.1→43.8KB（+4.2%）、webfont 21.8→31.3KB：增量全部是恢复字形覆盖的正确性成本；对比 v1.0.15 累计仍为每页资产 -47.7%、webfont -60.4%、部署 -47.6%。
- 改文案后必须「先 build 再 gen:uifonts」（脚本扫描 dist）——顺序已写入 font-subset 笔记。
